# Асылбек Арслан

Демонстрационный интернет-магазин спортивной одежды и экипировки. Независимый вымышленный бренд, не связанный с другими марками.

## Возможности

- Каталог с поиском и фильтрами по категории, размеру, цвету, цене и наличию.
- Страницы товаров с галереей, описанием, характеристиками и выбором размера и цвета.
- Корзина с изменением количества, расчётом доставки и сохранением в localStorage.
- Адаптивная навигация, главная с коллекциями, информация о бренде и контакты.

Товары и цены демонстрационные. Оплата и реальное оформление заказа не подключены. Изображения загружаются с Unsplash.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Для production-сборки выполните `npm run build`, для локального просмотра сборки — `npm run preview`.
